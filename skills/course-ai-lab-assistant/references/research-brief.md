# Research Brief: Classroom AI Use

Use this reference when the user asks why this framework is pedagogically defensible, wants sources, or needs school-facing rationale.

## Sources To Cite

1. UNESCO, *Guidance for generative AI in education and research* (2023, updated page 2026)
   - Emphasizes a human-centered approach, ethical/safe/equitable use, and pedagogical design for GenAI in education.
   - Link: https://www.unesco.org/en/articles/guidance-generative-ai-education-and-research

2. UNESCO, *AI competency framework for teachers* (2024)
   - Defines teacher AI competencies across human-centered mindset, AI ethics, AI foundations/applications, AI pedagogy, and professional learning.
   - Progression levels: Acquire, Deepen, Create.
   - Link: https://www.unesco.org/en/articles/ai-competency-framework-teachers

3. Stanford Teaching Commons, AI literacy framework
   - Four intersecting domains: functional, ethical, rhetorical, pedagogical AI literacy.
   - Useful for keeping classroom AI use tied to both tool understanding and teaching practice.
   - Link: https://teachingcommons.stanford.edu/teaching-guides/artificial-intelligence-teaching-guide/understanding-ai-literacy

4. TeachAI / AI Literacy Framework resources
   - Defines AI literacy as technical knowledge, durable skills, and future-ready attitudes.
   - Stresses practical classroom implementation resources and exemplars.
   - Link: https://www.teachai.org/ailiteracy

5. AI Assessment Scale (Perkins, Furze, Roe, MacVaugh)
   - Provides levels for permitted AI use in assessment, from no AI to AI exploration.
   - Useful for making student AI use transparent instead of hidden.
   - Link: https://aiassessmentscale.com/

6. LAIR Framework
   - Literacy, Application, Interpretation, Responsibility.
   - Useful as a quick classroom check: do students understand, apply, evaluate, and use AI responsibly?
   - Link: https://learningaiinstitute.org/lair-framework

7. EQAITE Framework
   - Stresses pedagogical value, educator autonomy, assessment validity, evidence, and learner agency.
   - Useful for evaluating whether an AI classroom tool supports learning rather than just productivity.
   - Link: https://eqaite.org/framework/

## Synthesis For Programming Courses

Existing AI education frameworks are broad. For a programming class, adapt them into a practical loop:

```text
teacher explains concept -> AI helps externalize the concept -> students critique AI output
-> AI helps scaffold a small program -> students modify and verify
-> AI creates visuals and explanation prompts -> students orally defend the implementation
```

The most important design choice is requiring students to connect AI output back to lecture concepts and runnable code. Without this connection, AI use becomes substitution. With this connection, AI becomes a visible thinking partner and classroom discussion object.

## Recommended Classroom Stance

- Teacher controls the prompt and the allowed AI-use level.
- Students see AI make both useful suggestions and mistakes.
- The class evaluates AI output against the lecture, not the other way around.
- Final assessment includes explanation, code tracing, modification evidence, and verification.
- AI-generated diagrams and summaries are acceptable only when students can explain and correct them.

## Risks And Mitigations

| Risk | Mitigation |
|---|---|
| Students copy code they do not understand | Require code walkthrough and teacher Q&A |
| AI introduces advanced frameworks | Add explicit course boundary to every prompt |
| AI output contains subtle bugs | Require build/run/test evidence |
| Students over-rely on AI | Require manual modification and reflection |
| Assessment becomes unclear | Set AI-use level before the task |
| Privacy or copyrighted materials are mishandled | Avoid personal data and follow school policy |
