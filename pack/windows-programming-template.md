# Windows 程序设计课专用模板

适用于 C++、Win32、MFC、GDI、文档-视图、对话框、控件、菜单、文件保存等课程内容。

## 常见知识点映射

| 课堂知识点 | 代码/API | 程序表现 | 学生讲法 |
|---|---|---|---|
| 程序入口 | `WinMain` | 创建窗口并进入消息循环 | Windows GUI 程序从 WinMain 开始 |
| 消息循环 | `GetMessage` / `DispatchMessage` | 程序持续响应操作 | Windows 程序是消息驱动的 |
| 窗口过程 | `WndProc` | 处理各种窗口消息 | 所有消息先进入窗口过程 |
| 菜单/按钮命令 | `WM_COMMAND` | 点击菜单触发功能 | 命令通过 ID 区分 |
| 鼠标消息 | `WM_LBUTTONDOWN` / `WM_MOUSEMOVE` / `WM_LBUTTONUP` | 拖拽交互 | 按下开始，移动更新，松开结束 |
| 窗口重绘 | `WM_PAINT` / `BeginPaint` / `EndPaint` | 遮挡缩放后恢复显示 | 正确绘图要能重绘 |
| 设备环境 | `HDC` / `CDC` | 绘图目标 | GDI 通过 DC 绘制 |
| 画笔 | `CreatePen` / `CPen` | 控制线条 | 画笔控制颜色、粗细、线型 |
| 画刷 | `CreateSolidBrush` / `CBrush` | 控制填充 | 画刷填充矩形、椭圆 |
| 文档-视图 | 文档类 + 绘制函数 | 数据和显示分离 | 文档保存数据，视图显示数据 |
| 序列化 | `Serialize` / `Save` / `Load` | 保存和恢复数据 | 保存可编辑数据，而不是只截图 |

## 标准实验路线

以画图程序为例：

```text
版本 0：创建窗口，能处理 WM_PAINT
版本 1：用 GDI 画一条固定直线
版本 2：用鼠标拖动画线
版本 3：增加矩形、椭圆、画笔、画刷
版本 4：把每一笔保存成数据
版本 5：WM_PAINT 根据数据重绘，解决图形丢失
版本 6：增加保存/打开/导出
版本 7：生成架构图、流程图和验收讲稿
```
