# 示例：把 GDI 课程变成画图实验

这个示例可以给 Agent 作为参考。

## 输入

```text
课程：Windows 程序设计
主题：MFC 文档-视图结构与 GDI 图形基础
老师强调：
1. 文档负责数据，视图负责显示
2. GDI 使用 DC、画笔、画刷绘图
3. WM_PAINT 负责正确重绘
任务：参考 PaintORama 做一个类似但不完全一样的画图程序
允许：C++、Win32、MFC、GDI
禁止：Qt、Direct2D、OpenGL、Web 前端
```

## AI 应输出的最小路线

```text
版本 0：创建窗口
版本 1：WM_PAINT 中画固定线条
版本 2：鼠标拖动画线
版本 3：加入矩形和椭圆
版本 4：把图形保存成 Stroke 数据
版本 5：WM_PAINT 从 Stroke 数据重绘
版本 6：加入保存 .psp 和导出 .bmp
```

## 核心讲法

```text
参考项目主要是直接画到窗口上，窗口刷新后图形容易丢。
改进版把每一笔图形保存成 Stroke 数据。
鼠标负责产生数据，WM_PAINT 负责显示数据。
这体现了文档-视图结构和 GDI 绘图思想。
```

## 老师可能问

```text
Q：为什么要保存 Stroke？
A：因为窗口刷新时需要重新画，只有保存数据才能恢复图形。

Q：HDC 是什么？
A：设备环境，GDI 绘图必须画到 DC 上。

Q：画笔和画刷区别是什么？
A：画笔控制线条，画刷控制填充。

Q：.psp 和 .bmp 区别是什么？
A：.psp 保存可编辑数据，.bmp 是导出的图片结果。
```
