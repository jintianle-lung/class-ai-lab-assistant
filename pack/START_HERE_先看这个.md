# 先看这个：CLASS-AI 傻瓜式使用说明

这个包是给 Trae、Resonix、DeepSeek、Claude、ChatGPT 等 Agent 用的。

你不需要理解里面的所有文件，只按下面做。

## 最简单用法

### 第 1 步：上传这个文件夹或压缩包

上传：

```text
CLASS-AI-Agent-Pack.zip
```

如果 Agent 不认识 zip，就把这个文件夹里的 `.md` 文件全部上传。

### 第 2 步：复制这句话给 Agent

```text
请严格按照 CLASS-AI-Agent-Pack 里的《傻瓜式课堂实验向导.md》工作。
你不要一次性生成完整结果。
你要像问卷一样一步一步问我，每次只问一个问题，给我选项。
我回答后，你再进入下一步。
现在开始。
```

### 第 3 步：按它的问题回答

它会依次问你：

```text
1. 你是老师还是学生？
2. 课程叫什么？
3. 本节课主题是什么？
4. 有没有 PPT？
5. 老师讲了哪些重点？
6. 作业要求是什么？
7. 学生水平如何？
8. 允许/不允许用什么技术？
9. 你想生成什么？
```

你不会答也没关系，选“不确定，让 AI 帮我判断”。

## 推荐给老师的话术

```text
我上传了课堂 PPT 和实验要求。
请按傻瓜式课堂实验向导，一步步帮我生成：
课堂知识点、课上 AI 互动、最小实验、逐步改进路线、图解、学生讲稿和老师问答。
```

## 推荐给学生的话术

```text
我上传了老师 PPT、课堂笔记和作业要求。
请按傻瓜式课堂实验向导，一步步带我完成实验。
不要直接给最终答案，先帮我理解知识点，再做最小版本，最后生成验收讲稿。
```

## 最终会得到什么

Agent 最终会生成：

```text
1. 本节课知识点整理
2. 知识点到代码/实验映射表
3. 课堂 AI 互动问题
4. 最小可运行实验
5. 逐步改进路线
6. 项目实现建议或代码
7. 架构图
8. 流程图
9. 关键代码讲解
10. README 或实验说明
11. 学生验收讲稿
12. 老师可能提问和回答
13. 学生复盘
```

## 如果 Agent 跑偏了

复制这句话纠正它：

```text
请回到傻瓜式课堂实验向导。
不要直接生成完整项目。
请从当前阶段继续，一次只问我一个问题，并给我选项。
```
