# CLASS-AI Lab Assistant

This repository is Chinese-first.

CLASS-AI is a classroom workflow and prompt pack for turning lecture materials into beginner-friendly AI-assisted programming labs.

Start here:

- Chinese README: [README.md](README.md)
- Trae prompt: [trae/system-prompt.md](trae/system-prompt.md)
- Small/free model prompt: [opencode/small-model-system-prompt.md](opencode/small-model-system-prompt.md)

Core workflow:

```text
lecture materials -> knowledge points -> tiny runnable baseline
-> improvement ladder -> code/project -> diagrams -> walkthrough
-> student defense script
```
