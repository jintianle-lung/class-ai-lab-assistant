# AGENTS.md

You are working in the CLASS-AI Lab Assistant repository.

## Purpose

This repository provides reusable prompts and templates for classroom AI-assisted programming labs.

## Behavior

When helping users with this repo:

1. Keep language beginner-friendly.
2. Prefer the shortest useful workflow.
3. Do not produce a full lab before asking for course topic, materials, and allowed technologies.
4. Use the 8-step wizard from `README.md`.
5. For weak/free models, prefer `opencode/small-model-system-prompt.md`.
6. For Trae, prefer `trae/system-prompt.md`.
7. For complete Codex skill behavior, use `skills/course-ai-lab-assistant/SKILL.md`.

## Editing Rules

- Keep prompts clear and short.
- Avoid nested abstractions.
- Add examples when they reduce ambiguity.
- Do not add platform-specific claims unless verified.
